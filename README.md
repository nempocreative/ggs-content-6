# GGS Calender 2

buatkan power point untuk penjadwalan konten GGS Beauty dan GGS Hair Studio
bisa ambil data dari sini keperluan logo dan lainnya https://github.com/nempocreative/remix-of-ggs-5

mulai tanggal 4/11/2026
komposisi konten
- GGS Talk (Ngopi Sore)
- Komedi (Si Elis)
- Video Cinematic Treatment
- Ngobras (Ngobrol santai) bareng konsumen sambil treatment
- Promo

jadi ini komposisi nya dibuat perhari 3 konten, tapi jangan video semua di mix
buat rapih dan menarik dan konsep warna cewek pink dan cowok hitam gold
